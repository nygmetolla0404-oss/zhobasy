# zhobasy

Іске қосу: `index.html` файлын браузерде ашыңыз (сервер қажет емес).

Фотосуреттер: Wikimedia Commons (авторлары мен лицензиялары сайттағы «Жоба туралы» бөлімінде көрсетілген).
